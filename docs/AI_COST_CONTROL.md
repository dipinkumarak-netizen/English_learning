# AI cost control

AI is disabled by default. When enabled, the backend applies configurable per-user daily request and token limits, maximum message size, bounded recent context, output-token limits, and duplicate operation IDs. Usage records store provider/model, token estimates, status, latency, and optional cost—never full learner message text.

Limits are technical safety and abuse controls for this private personal-use application, not paid-tier restrictions. No Redis or payment system is added in Phase 4. Provider pricing is intentionally not hard-coded; cost estimates remain optional configuration work.
